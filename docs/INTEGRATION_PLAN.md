# Standalone decision

This release is not intended to be merged into the older Ordeal repository. `ordeal_agent` is the optional local SDK; `ordeal_platform` is its standalone team server, and `sdks/typescript` is the telemetry/control-plane client. Their compatibility boundary is a versioned JSON API/report format. See `ARCHITECTURE.md` and `enterprise/CAPABILITY_MATRIX.md` instead of the previous merge-oriented roadmap.
